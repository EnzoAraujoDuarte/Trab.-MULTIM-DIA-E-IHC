# Gerenciador de Tarefas

Um aplicativo web moderno para gerenciamento de tarefas, desenvolvido com Next.js e Tailwind CSS.

## Funcionalidades

- Adicionar novas tarefas
- Editar tarefas existentes
- Marcar tarefas como concluídas
- Excluir tarefas
- Filtrar tarefas por status (Todas, Pendentes, Concluídas)
- Interface responsiva e moderna
- Feedback visual para todas as ações
- Acessibilidade implementada

## Tecnologias Utilizadas

- Next.js
- React
- Tailwind CSS
- Lucide React (ícones)

## Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/EnzoAraujoDuarte/Trab.-MULTIM-DIA-E-IHC.git
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o projeto:
```bash
npm run dev
```

4. Acesse o projeto em `http://localhost:3000`

## Modelo de Shneiderman

Este projeto foi desenvolvido seguindo os princípios do modelo de Shneiderman para design centrado no usuário:

1. **Especificações**
   - Cores e layout consistentes
   - Terminologia clara
   - Feedback visual para todas as ações

2. **Ferramentas de Prototipagem**
   - Next.js para desenvolvimento
   - Tailwind CSS para estilização
   - Lucide React para ícones

3. **Testes de Usabilidade**
   - Feedback visual imediato
   - Acessibilidade implementada
   - Interface intuitiva
   - Tratamento de erros
   - Sequência lógica de ações
